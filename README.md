# 💪 Diario de Entrenamiento (PWA)

Aplicación web progresiva (PWA) ligera, autónoma y optimizada científicamente para el registro y sobrecarga progresiva de entrenamientos de hipertrofia.

## 🚀 Características
- **Rutina Optimizada de 5 Días:** Estructura científica de volumen y estímulo/fatiga (RIR 0–1).
- **⏱️ Temporizador de Descanso:** Rest timer integrado con selector rápido (60s, 90s, 2m, 2.5m, 3m), audio suave y vibración háptica.
- **🔥 Detección de PR (Sobrecarga Progresiva):** Notificación visual en vivo al superar marcas previas (+kg o +reps).
- **📱 PWA & Offline First:** Instalable en móvil (iOS / Android) y funcional sin conexión.
- **💾 Copia de Seguridad:** Exportación e importación segura en JSON y Web Share API.
